# Travel Explorer

Reusable destination cards, trip highlights, navigation and itinerary panels.

## Run locally
1. Install Node.js (LTS) and Git.
2. Open this project folder in VS Code or a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## React concepts practiced
- Functional components and component composition
- Reusable components with props
- Rendering lists with `.map()` and stable `key` values
- Separating UI into `src/components/`
- CSS layout and responsive design
